# Vision

Radar is built to be more than a price search app.

## What the product should become
- a reliable regional price intelligence layer
- a clean comparison tool for digital subscriptions
- a cross-platform foundation for web, Telegram, and mobile
- a system that can absorb new services and regions without redesigning the core

## Principles
- store once, serve fast
- keep source collection separate from user requests
- prefer adapters over special cases
- avoid logic duplicated in the UI
- make future surfaces consume the same domain model

## Five-year expansion target
The codebase should be ready for:
- multiple clients
- multiple data sources
- multiple notification channels
- analytics dashboards
- admin moderation and observability
- safe experimentation without breaking the MVP
