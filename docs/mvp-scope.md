# MVP Scope

## Must have
- search by subscription name
- list regional prices from stored data
- sort by lowest price
- convert prices to the user's currency
- show last refresh time
- provide a clean responsive UI

## Must not have
- live scraping on every request
- user accounts
- Telegram notifications
- charts
- mobile app
- advanced analytics
- multi-step onboarding

## Success criteria
The MVP is successful when:
- it responds quickly
- it is easy to extend
- it does not mix parsing logic with UI logic
- every future feature can be added without rewriting the core
