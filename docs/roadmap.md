# Roadmap

## MVP
- search by subscription name
- region price list
- currency conversion
- fastest possible read path from the database
- basic responsive UI

## Version 2.0
- Telegram notifications
- price history charts
- mobile app
- plan comparison
- user accounts
- usage analytics

## Version 3.0+
- multiple source adapters
- personalization
- alert rules
- saved comparisons
- regional recommendations
- admin tooling

## Long-term direction
The system should remain modular for at least the next five years:
- each new surface should be an additional client, not a rewrite
- each new data source should be an adapter
- each new insight should be derived from stored events
- each new feature should avoid coupling the UI to parsing logic
